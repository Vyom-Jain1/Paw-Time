# Paw-Time 🐾

E-Commerce platform for Dogs and Cats

## Services

### Product Service (Anmol)

Backend service for Paw-Time E-Commerce

## Tech Stack

- Java 21
- Spring Boot 4.0.8
- MySQL
- Spring Data JPA

## Port

Running on: 8081

## APIs

- GET /api/products
- GET /api/products/{id}
- GET /api/products/category/DOG
- GET /api/products/category/CAT
- POST /api/products
- PUT /api/products/{id}
- DELETE /api/products/{id}
